# Brand Direction Worksheet

Complete this brief **before** touching code or CSS. This worksheet bridges the gap between "removing clichés" and "designing an authentic brand experience."

---

### 1. Audience & Context
* **Who reads this page?** (e.g. Specialty coffee shop owners and discerning home brewers looking for freshly roasted single-origin lots).
* **Primary Device & Viewport**: (e.g. Mobile-first 390px vs Desktop 1280px).
* **Language & Direction**: (e.g. Arabic RTL primary, English LTR secondary).

### 2. Brand Identity in 3 Adjectives
Derived strictly from the brand’s actual history, products, and physical environment (never generic words like "modern", "clean", or "innovative"):
1. **Adjective 1**: (e.g. Maritime / بحري)
2. **Adjective 2**: (e.g. Artisanal / حرفي)
3. **Adjective 3**: (e.g. Grounded / أصيل)

### 3. The Single Visual Idea
One concrete visual concept rooted in the brand's physical reality (e.g. an old harbour customs ledger, a copper roasting drum, a workshop serial tag, a chemist's formulation sheet).
* **The Concept**: (e.g. An Alexandria customs harbor ledger and copper lot stamp).
* **Appearance 1**: (e.g. Customs batch stamp badge with roaster specs and dispatch dates in the hero).
* **Appearance 2**: (e.g. Transparent sourcing ledger table showing elevation, process, and bag prices).

### 4. Color System
* **Dominant Brand Color**: (Derived from physical product: e.g. Deep Roast Espresso `#181310`).
* **Neutral Family**: (e.g. Warm Aged Paper `#F9F7F2` and Subtle Surface `#F1ECE1`).
* **Accent Color**: (e.g. Roasting Copper `#B85226` for primary CTAs and status stamps).
* **Contrast Target**: WCAG AAA for body text (>7:1), AA for all controls.

### 5. Typographic Hierarchy
* **Display Font (Headings / Wordmark)**: (e.g. *Amiri* / *Newsreader* for editorial presence).
* **Body Font (Reading / Specs)**: (e.g. *IBM Plex Sans Arabic* / System Humanist Sans).
* **Scale Multiplier**: 1.25x between heading levels; `h1` at least 2.5x body text size.

### 6. Layout Composition
* **Default Alignment**: Start-aligned (Right-aligned in RTL, Left-aligned in LTR).
* **Rhythm**: Section 1 = Asymmetric hero with customs slip card; Section 2 = Sourcing data table; Section 3 = Two-column craft history and attributed customer proof.
* **Card Grid Limit**: Max 1 per page (zero used here, replaced with an authentic data table).

### 7. Copy & Conversion
* **Primary Action Label**: (e.g. "احجز تحميصة الدفعة 42 (الشحن الخميس)" / "Reserve Batch #42").
* **Banned Words**: unlock, seamless, game-changer, افتح قوة, لا مثيل لها, ابدأ الآن.
* **Em Dash Budget**: Maximum 0-1 on the entire page.
